# MèmeDex 🃏

Jeu de cartes à collectionner sur les mèmes et la culture internet française.
Un seul `index.html` + un dossier `images/`. Aucune installation.

**Nouveautés de cette version**
- 94 cartes (dont plein de vraies réfs FR : Cheikh t'as pas volé de pain, C'est pour les travaux, Taisez-vous !, Non mais allô, Omar m'a tuer…)
- Profils locaux (pseudo + avatar, plusieurs profils par appareil, chacun sa collection)
- Boosters de **5 cartes**, ouverture en carrousel, 6 raretés + Shiny ✨
- Addictif : série quotidienne 🔥, niveaux + XP, paliers de collection (25/50/75/100%)
- Boosters gratuits : 10/jour + 1 toutes les 10 min
- Progression sauvegardée dans le navigateur

---

## 🖼️ Les images des cartes (IMPORTANT)

Les images vivent dans le dossier **`images/`**. Chaque carte charge `images/<identifiant>.jpg`.
- Exemple : `images/jul.jpg`, `images/cheikh.jpg`, `images/pogba.jpg`
- La **liste complète des noms** est dans `images/_LISTE_CARTES.txt`
- Sans image, la carte affiche un visuel stylisé propre (le jeu reste jouable).
- Pour ajouter une image : capture d'écran → renomme avec l'identifiant → mets-la dans `images/`.

Sur GitHub : ouvre le dossier `images/` → **Add file → Upload files** → dépose tes images.

---

## 🚀 Mettre en ligne (GitHub Pages — gratuit)

1. **github.com** → **New** → nom du dépôt, coche **Public** → **Create repository**.
2. **Add file → Upload files** → dépose `index.html` ET le dossier `images/`
   (glisse le dossier entier, ou crée `images/` et upload les fichiers dedans) → **Commit changes**.
3. **Settings → Pages** → Source : *Deploy from a branch* · Branch : `main` / `/(root)` → **Save**.
4. ~1 min plus tard : ton lien **https://TON-PSEUDO.github.io/NOM-DU-REPO/**

Partage ce lien à tes potes : chacun ouvre, crée son profil et joue de son côté.

> Mise à jour plus tard : réuploade `index.html` (même nom) ou ajoute des images dans `images/`.
> Le lien ne change pas.
